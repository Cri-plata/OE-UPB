# Instrucciones para la IA (Claude / Asistentes)

Este proyecto se llama **OE UPB (Observatorio de Egresados UPB)**.

## Reglas del Repositorio (Fase PI3)
- El alcance actual está limitado al MVP para séptimo semestre (PI3).
- Las tecnologías aprobadas son: Angular (Frontend), Python (Backend) y MySQL (Base de Datos).
- Se aplica un paradigma "Local-First" básico para soportar la visualización sin conexión a internet.
- Los usuarios activos en esta fase son únicamente Administradores/Coordinadores. No asumas flujos para egresados como usuarios finales todavía.
