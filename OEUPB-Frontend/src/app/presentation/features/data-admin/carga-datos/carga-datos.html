Instrucciones de Uso

  1. 1. Selecciona el Momento de Medición correspondiente al archivo que vas a subir.
  2. 2. Asegúrate de que tu Excel contenga las columnas obligatorias oficiales del Ministerio.
  3. 3. Arrastra el archivo a la zona de carga (solo archivos .xlsx).
  4. 4. El algoritmo procesará automáticamente las dobles titulaciones.
